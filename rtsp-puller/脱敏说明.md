# 脱敏说明（rtsp-puller）

本仓库为「门店监控录像本地归档工具」的**脱敏副本**，用于对外公开/分发。所有真实凭据与现场信息已替换为占位符。

## 〇、业务实体脱敏（商业机密 / 公民隐私）

为不体现任何商业机密与公民隐私，仓库内**不包含任何稽核报告文档**，且所有门店名、摄像头名均已替换为占位符：

| 原值（现场） | 仓库内占位 |
|---|---|
| 门店名（杭州/上海等地门店） | 测试门店A、<门店名> |
| 通道/摄像头名（现场真实通道名） | 通道1、通道A、<摄像头2> |

## 一、凭据脱敏规则

| 原值（现场） | 仓库内占位 | 出现位置 |
|---|---|---|
| 录像机真实 IP（192.168.1.x 段） | `192.168.2.10`（示例段） | `config.example.json`、README、docs、报告、测试 |
| 其他内网 IP（同段各地址、10.0.0.x） | `192.168.2.11~15`、`192.0.2.x`（RFC 5737 测试地址） | 相关文档、测试文件 |
| NVR 密码 | `<NVR_PASSWORD>` | `config.example.json`、`device_identity_probe.py`、`schedule_test.py`、README |
| FTP 密码 | `<FTP_PASSWORD>` | `config.example.json`、`ftp_receiver.py`、测试 |
| 本机用户名路径 | `/Users/<用户名>/...` | 相关文档 |

## 二、部署时需替换

1. `config.example.json` → 复制为 `config.json`，替换：
   - `nvr.host`（占位 `192.168.2.10`）→ 真实录像机 IP
   - `nvr.password`（`<NVR_PASSWORD>`）→ 真实密码
   - `ftp.user` / `ftp.password`（`<FTP_PASSWORD>`）→ 真实 FTP 账号
2. 测试/工具脚本中的占位 IP（`192.168.2.x`、`192.0.2.x`）→ 现场地址（仅测试时需要）

## 三、已排除内容（未随仓库分发）

| 类别 | 内容 | 原因 |
|---|---|---|
| 运行时数据 | `state/`（设备配置导出 `device_config_all*.txt` 等） | 含设备完整配置，可能含更多凭据 |
| 日志 | `logs/` | 含现场运行记录 |
| 收件箱 | `ftp-inbox/` | 真实录像文件 |
| 二进制 | `bin/ffmpeg.exe`（约 87MB） | 体积，自行安装 |
| AI 助手记忆 | `.workbuddy/` | 内部工作记录 |
| 系统垃圾 | `.DS_Store`、`._*`、`__pycache__` | 无价值 |

## 四、验证

脱敏后已做全库扫描：真实密码、真实 IP、用户名 **0 残留命中**。
